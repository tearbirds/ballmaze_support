## このアプリについて

端末を傾けて鉄の玉を転がし、穴を避けてゴールまで運ぶ迷路ゲームです。全 40 面。
坂道・段差・氷・ゴムの壁・回る棒があり、床がガラスのステージでは背面カメラで
盤の向こう側を透かせます（カメラの映像は画面に出すだけで、保存も送信もしません）。
