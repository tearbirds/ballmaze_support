## このアプリについて

えんにちと、ちいさいころのあそびを 1 本にまとめたゲーム集です。いまは 2 つ入っています。

- **きんぎょすくい** … ポイで金魚をすくいます。ポイは 3 本、時間制限はありません。
- **玉ころがし** … 端末を傾けて鉄の玉を転がし、穴を避けてゴールまで運びます。全 40 面。
  坂道・段差・氷・ゴムの壁・回る棒があり、床がガラスのステージでは背面カメラで
  盤の向こう側を透かせます（カメラの映像は画面に出すだけで、保存も送信もしません）。
